Welcome to Git & GitHub

Explore the world of Version Control Systems. Learn how developers manage source code, track changes and collaborate on software projects using Git and GitHub.

Introduction to Version Control

Version Control is a system that records changes made to files over time. It allows developers to track modifications, restore previous versions and collaborate efficiently. Git is a distributed version control system, while GitHub is a cloud-based platform for hosting and managing Git repositories.

Core Concepts of Git & GitHub

1. Git

Git is a distributed version control system used to track source code changes and manage different versions of a project.

2. GitHub

GitHub is an online platform that hosts Git repositories and supports collaboration between developers.

3. Repository

A repository stores project files, source code and the complete history of changes made during development.

4. Version Control

Version control helps maintain different versions of files and makes it easier to track and manage changes.

5. Branching & Merging

Branching allows developers to work on separate features, while merging combines changes into the main branch.

6. Collaboration

GitHub enables multiple developers to work together using commits, pull requests, code reviews and issue tracking.

7. Git Bash

Git Bash provides a command-line environment to execute Git commands and manage repositories on Windows.

8. Remote Repository

A remote repository is hosted on platforms like GitHub and allows developers to share and synchronize project code.

9. Commits

A commit records a snapshot of changes in the repository along with a message describing the modifications.

Essential Git Commands

git init - Initialize a repository

git status - Check repository status

git add . - Stage all changes

git commit -m "message" - Save changes

git branch -M main - Rename the branch

git remote add origin URL - Connect GitHub

git push -u origin main - Upload files

git pull - Download remote changes

git clone URL - Copy a remote repository

Benefits of Git & GitHub

Code Management

Organizes project files and tracks every important modification.

Team Collaboration

Allows multiple developers to contribute to the same project.

Backup & Recovery

Maintains project history and helps recover previous versions.
